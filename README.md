# 팀 글냥이

팀 글냥이는 치지직 스트리머 [여까](http://yeokka.com/)님이 The Roottrees are Dead 번역을 위해 모집한 시청자들을 시작으로 구성된 비공식 유저 번역팀입니다.

여까님이 제안한 게임이나 번역자들이 관심 있는 게임을 중심으로 자발적인 유저 번역 한글 패치를 제작하고 있습니다.

## 유저 번역 한글 패치 | Fan Translations

> 각 번역 패치는 원작 개발사 및 퍼블리셔와 무관한 비공식 유저 번역입니다.
